Through these projects, I practiced:

* Data cleaning using Power Query
* Creating DAX measures and calculations
* Building interactive dashboards
* Data visualization and reporting

## Projects

* COVID-19 Global Cases Project
* Sales Disruption Project

## Tools Used

* Power BI Dekstop
* Power Query
* DAX
* Excel / CSV Datasets

These projects helped me gain hands-on experience working with real-world data and turning it into meaningful insights.

# Sales Disruption Project

This is a Power BI project where I analyzed sales and shipping data to identify disruptions that could affect business performance. The dashboard helps track delays, shipping costs, order trends, and high-risk shipments through interactive visualizations.

# The dashboard includes:
* Total Orders
* Average Delay
* Total Shipping Cost
* On-Time Delivery Percentage
* High-Risk Orders
* Sales and shipping trend analysis


# Tools Used
* Power BI
* Power Query
* DAX
* Excel/CSV Dataset

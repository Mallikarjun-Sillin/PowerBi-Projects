# COVID-19 Global Cases Dashboard

This is a Power BI project where I analyzed global COVID-19 data and created an interactive dashboard to understand the impact of the pandemic across different countries.

# The dashboard includes:
* Total confirmed cases
* Total deaths
* Total recoveries
* Active cases
* Country-wise comparisons
* Trend analysis over time

# Tools Used
* Power BI
* Power Query
* DAX
* Excel/CSV Dataset
